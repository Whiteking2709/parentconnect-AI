# ParentConnect AI

ParentConnect AI is an AI-powered school communication chatbot designed to help parents quickly access important school information.

## Project Overview

The chatbot was created using Dialogflow ES and connected to a custom HTML/CSS website using Dialogflow Messenger.

Parents can use the chatbot to access:

- Attendance
- Exams
- Fees
- Announcements
- Student Information
- Academics
- School Information
- Events
- Transport
- Documents
- Support

## Key Features

The chatbot uses **intents, entities and contexts** to understand user inputs and guide users through different sections.

It also includes:

- Context-based menu navigation
- Fallback handling for unknown inputs
- Multiple submenu options
- A custom web interface

## Testing

The chatbot was tested using realistic parent scenarios such as:

1. Checking attendance for a specific date
2. Viewing exam results
3. Checking fee payment history
4. Viewing student academic information
5. Checking upcoming events
